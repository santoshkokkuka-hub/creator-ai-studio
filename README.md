# Creator AI Studio

Build a professional AI YouTube Video Maker web application named "Creator AI Studio".

Design a modern, premium-looking, responsive dashboard.

The application must have these sections:

1. AI Story Generator

2. AI Script Generator

3. Telugu AI Voice Generator

4. Image Upload

5. Image to Video Maker

6. YouTube Shorts Maker (9:16)

7. My Projects

8. Download Videos

Design requirements:

- Dark premium theme.

- Simple and professional interface.

- Easy navigation.

- Responsive for desktop and mobile.

- Modern dashboard with sidebar.

- Clear buttons and input fields.

Important:

Build the complete frontend UI first.

Do not integrate any paid APIs yet.

Do not create fake working AI features.

Keep the architecture ready for future API integration.

Do not add unnecessary features.
